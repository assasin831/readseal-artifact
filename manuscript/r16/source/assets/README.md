# Figure Icons

analysis-icon.png and gpu-icon.png are original PNG assets extracted from the author-supplied r14 fig1_overview.pptx. Their pixels were preserved for the one-to-one reconstruction.

The supplied drawing code identifies them as Tabler's TbZoomCode and Phosphor's PiGraphicsCardBold, originally loaded through react-icons, under MIT licenses. This revision reuses those assets rather than downloading or generating replacements.

Other figure content is regenerated as native editable PowerPoint drawing and text elements from the supplied coordinates and CSV values.
